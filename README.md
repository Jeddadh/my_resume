# CV LaTeX Project — Build Instructions

This project contains automated build scripts to compile your LaTeX CV.  
It supports **per-customer branches**: each Git branch represents one client, and `make` automatically compiles all `.tex` files inside that branch's folder.

## 🚀 Quick Start

```bash
# On a customer branch (e.g. 2026.05.algovia.airbus):
#   → compiles all .tex files found in 2026.05.algovia.airbus/
make

# On main/master:
#   → compiles main.tex from root
make

# Force root mode from anywhere:
make CUSTOMER=

# Quick one-pass build (for minor changes)
make quick

# Clean auxiliary files
make clean

# Clean everything including PDFs
make cleanall

# Show help
make help
```

## 📁 How It Works

### Per-Customer Branches

Each customer gets their own **Git branch** and a **folder named after the branch**.

```
repo/
├── altacv.cls               ← shared class file
├── main.tex                 ← your base resume (used on main/master)
├── Makefile                 ← auto-detects the branch
│
├── 2026.05.algovia.airbus/  ← Airbus DAISEI (branch name = folder name)
│   ├── 2026.05.algovia.airbus.tex  ← same name as branch
│   └── 2026.05.algovia.airbus.pdf  ← generated by make
│
├── 2026.06.acme_corp/       ← another customer (future)
│   ├── 2026.06.acme_corp.tex
│   └── 2026.06.acme_corp.pdf              ← generated by make
```

When you run `make`:

| You are on…                | `make` compiles…                              | Output goes to… |
|----------------------------|-----------------------------------------------|-----------------|
| `main` or `master`         | `main.tex` (from root)                        | Root directory  |
| A feature branch           | **All `.tex` files inside** `<branch-name>/`  | `<branch-name>/` |

### Auto-detection Logic

```bash
# On a branch → compiles files inside that branch folder
git checkout 2026.05.algovia.airbus
make
# → compiles 2026.05.algovia.airbus/*.tex

# On main   → compiles main.tex from root
git checkout main
make
# → compiles main.tex
```

### Override

```bash
# Force root mode from any branch:
make CUSTOMER=

# Specify a different customer folder:
make CUSTOMER=some_other_folder
```

## ✏️ Working with a New Customer

1. **Create a branch** named after the customer:
   ```bash
   git checkout -b 2026.06.acme_corp
   ```

2. **Create a folder** with the same name:
   ```bash
   mkdir -p "$(git branch --show-current)"
   ```

3. **Create your `.tex` file** named after the branch inside that folder:
   ```bash
   touch "$(git branch --show-current)/$(git branch --show-current).tex"
   ```
   (Copy from `main.tex` or write fresh.)

4. **Build**:
   ```bash
   make
   ```
   This compiles all `.tex` files inside the folder and outputs the PDF(s) there.

5. **Commit & push**:
   ```bash
   git add <branch-folder>/
   git commit -m "feat: add tailored resume for Acme Corp"
   git push origin <branch-name>
   ```

6. **Merge back to master** when ready:
   ```bash
   git fetch origin master
   git rebase origin/master
   git checkout master
   git merge <branch-name>
   git push origin master
   ```

## 📦 Output Naming

- **On a branch**: the PDF is named after the branch (e.g. `2026.05.algovia.airbus.tex` → `2026.05.algovia.airbus.pdf`).
- **On main/master**: a date-based name is generated:
  ```bash
  make
  # → cv_hamza_jeddad_detailed_resume_en_YYYYMMDD.pdf
  ```
- **Custom name** (any branch):
  ```bash
  make OUTPUT_NAME=my_custom_name
  # → <branch-folder>/my_custom_name.pdf   (or root on main/master)
  ```

## 🧹 Cleaning

```bash
# Remove auxiliary files (.aux, .log, etc.) from root AND current branch folder
make clean

# Remove everything including PDFs
make cleanall
```

## ⚙️ Requirements

- `pdflatex` — LaTeX compiler
- `bibtex` — Bibliography processor (if using citations)
- `make` — Build automation tool

## 🔧 Troubleshooting

- **`altacv.cls` not found**: this file must be in the **root** of the project. The Makefile compiles from the root using `-output-directory=<folder>`, so the `.cls` is found.
- **Compilation fails**: check for syntax errors in your `.tex` file.
- **No `.tex` files found**: make sure you created the folder matching the branch name and placed `.tex` files inside.
